# Documentation

This folder contains internal documentation, development notes, and detailed guides for the SageMaker AI LLM Model Customization Challenge Automation project.

## 📁 Folder Structure

### `/guides/`
User-facing setup and configuration guides:
- **SETUP.md** - Detailed setup instructions for development environment

### `/docs/`
Technical documentation and guides:
- **AWS_CLIENT_MANAGER.md** - AWS client management documentation
- **LOGGING_GUIDE.md** - Logging configuration and best practices
- **MYPY_GUIDE.md** - Type checking with mypy

### `/docs/implementation/`
Implementation summaries and development notes (internal):
- Component implementation summaries
- Task completion reports
- Development decision records
- Fix documentation

### Root Documentation Files
- **DIRECTORY_STRUCTURE.md** - Complete project directory structure
- **GITHUB_PUSH_CHECKLIST.md** - Pre-publication checklist
- **SECURITY_QUICK_REFERENCE.md** - Quick security reference card

## 📚 For Users

If you're setting up the project for the first time, start with:

1. **Main README.md** (in project root) - Overview and quick start
2. **guides/SETUP.md** - Detailed setup instructions
3. **SECURITY.md** (in project root) - Security best practices

## 🔧 For Developers

If you're contributing to the project:

1. Review **docs/** for technical documentation
2. Check **docs/implementation/** for component details
3. Follow patterns documented in implementation summaries
4. Refer to **DIRECTORY_STRUCTURE.md** for project organization
